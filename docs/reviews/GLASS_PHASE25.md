# Liquid Glass phase2.5 — local only

Production changes in this phase: GlassSurface.java and IosStyle.java. GlassBackdrop.java remains unchanged: its existing bounded wallpaper cache is reused. No dashboard/dock/drawer/Control Center geometry, controls, dependencies or manifest changes were introduced in this phase. Existing uncommitted work from earlier phases remains separate. No commit or push.

Visual: dual thin graduated rims (.85/.65dp), curved fading specular Path (3.5dp BALANCED/5.5dp HIGH),3dp inner bevel with restrained light/shadow. Light surfaces use a paler adaptive body and dark ink; dark surfaces retain bright foregrounds. A weakly tracked contrast helper updates eligible bright TextViews and direct glass glyphs on the UI queue; nested colored backgrounds are excluded, semantic dark/accent colors retained, and original bright colors restored for Dark Glass. Drawable wrapper callbacks are followed to the owning View. Full interactive/floating-window color-state behavior has not been visually certified.

Refraction is an optical lighting approximation, not true pixel displacement. No MRiOS shader/code/assets copied. No per-frame bitmap allocation or pixel processing; cached gradients/Path rebuilt only on bounds/cache revision changes. Shadows remain inset approximations plus whatever elevation existing Views already have.

LOW retains frost/body/simple rim; BALANCED(default) adds curved reflection and inner depth; HIGH broadens the specular accent with the existing higher-resolution cache. Non-solid textured draw-call estimate from source: LOW~6, BALANCED/HIGH~10 versus phase2 BALANCED~7; this is not measured GPU overdraw or FPS. Cached bitmap caps remain64/196/400KiB (square LOW/BALANCED/HIGH), checked using getAllocationByteCount against the tier cap. No new bitmap buffer is added by phase2.5; total process/driver/peak replacement memory is not profiled.

Validation: assembleDebug, assembleDebugAndroidTest, lintDebug PASS (0 errors; existing/new warnings recorded in Gradle lint output). Matching-signed API27 x86_64 emulator fixture:36 checks PASS, including cache identity across repeated draws, tier size/allocation caps, and six sampled foreground/background contrast ratios >=4.5:1. This does not certify WCAG across arbitrary wallpapers, all labels or icon states. Solid/transparent and full hardware-accelerated app/dialog captures are not part of this visual fixture.

Comparison: /workspace/output/idash-glass-phase2-vs-phase25.png, Android software Canvas. Left phase2 (frozen original renderer/base tokens), right phase2.5; light/dark blue, pink and neutral. White-to-dark text on Light Glass and brighter corner/rim/reflection are visible. Icons on colored tiles and head-unit ARM32/1GB FPS, RAM pressure and thermal behavior remain untested. Test changes: GlassRenderChecks.java and new Phase2GlassSurface.java snapshot. No release APK or GitHub artifact updated.
