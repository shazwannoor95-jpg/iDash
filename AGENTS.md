# iDash development

Read README.md and docs/DESIGN.md before implementation. This is a separate Android launcher project; NexaDash is paused. Keep iDash's package, data and signing configuration independent.

Do not claim app embedding, vehicle hardware support or physical performance based on layout previews or fixture tests. Preserve attribution for any reused source. Never commit private signing material, raw owner archives or personal diagnostic captures.

The repository contains the native Java launcher preview. Read docs/VALIDATION.md and dist/artifact.json before reporting release status. Build with JDK17, SDK35 and Gradle8.9; keep signing keys outside Git.
